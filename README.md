# File Encryption Tool Using Python

A Python tool that encrypts and decrypts any file using Fernet
symmetric encryption. Features secure key generation and binary
file handling. Tested on multiple real world files from live
websites. Encrypted output is completely unreadable without the
original secret key.

## Files
- generate_key.py - Generates and saves the encryption key
- encrypt.py - Encrypts any target file
- decrypt.py - Decrypts the encrypted file

## Tools Used
Python, Cryptography Library, Fernet Encryption, Kali Linux

## How to Run
1. Run generate_key.py to create your key
2. Run encrypt.py to encrypt your file
3. Run decrypt.py to decrypt it back
